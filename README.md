# Data-Science-Basketball-Statistic
This is a program for basketball scouters. It will help you give each basketball player a ranking. It will tell you the highest scorer, Lowest scorer and the average score. I made this program easy and simple to use!

## Features
-Tells you the highest scorer, lowest scorer and the average score
-Give you an accurate summary
-Easy and fun to use
